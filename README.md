# \## カタログ更新手順

# 

# 1\. PDFを更新する

# 2\. ファイル名を `catalog.pdf` にする

# 3\. GitHubフォルダへ上書きする

# 4\. GitHub Desktopを開く

# 5\. 変更内容を確認する

# 6\. Commit

# 7\. Push origin

# 8\. 30秒～1分待つ

# 9\. 公開ページで動作確認する

#
